# MOJO Latin

Cinematic editorial website for Mojo Latin Fusion (Forest Hills & Rockville Centre).

## Stack

Vite · React · TypeScript · Tailwind CSS · Framer Motion · Three.js (lazy, Flavor Map only)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Notes

- Outbound booking/social/maps URLs are centralized in `src/data/links.ts` and match the live Mojo sites.
- Media in `public/media/` is cinematic stand-in photography; swap with `@mojo_foresthills` assets when available.
